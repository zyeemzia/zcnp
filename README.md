# ZyeemZia™ Certified Network Professional (ZCNP)

**Live course: https://zcnp.zyeemzia.com/** · Book: https://zcnp.zyeemzia.com/book.html · PDF: https://zcnp.zyeemzia.com/ZCNP-Book.pdf

An independent certification track by ZyeemZia: interactive lessons, scenarios, case studies, templates,
flashcards, a timed certification exam, a capstone project and a downloadable certificate, plus a printable book.

## Structure

| Path | What |
|---|---|
| `index.html` | Interactive course (works offline after the first visit) |
| `book.html` | Printable book (Ctrl + P → Save as PDF) |
| `data/track.js` | Track settings: exam rules, capstone, certificate |
| `data/m*.js` | Modules, lessons and the exam bank |

Progress, notes and certificates are stored only in the learner's browser.
